# 2048 Letter Game 🎮

A Python implementation of the classic 2048 game, but with a twist: using **Letters** instead of numbers! Built using the `Tkinter` library.

## Features ✨
- **Letter-based Gameplay:** Merge letters (A + A = B, B + B = C, etc.) to reach higher letters.
- **Undo Capability:** Made a mistake? Use the Undo feature to revert your last move.
- **High Score Tracking:** Keeps track of your best score.
- **Simple GUI:** Clean and interactive user interface built with Python's built-in Tkinter.

## Prerequisites 🛠️

To run this game, you need to have Python installed on your system. `Tkinter` is included in the standard Python library, so no extra installation is required.

- Python 3.x

## How to Run 🚀
1. Clone the repository:
```bash
git clone https://github.com/taha-ravaghi/2048---letter---tkinter.git
```
2. Navigate to the project directory:
```bash
cd 2048---letter---tkinter
```
3. Run the game:
```bash
python ui_tk.py
```
